How the Regression Pipeline Works

When you click Predict, the input features are transformed using our scikit-learn ColumnTransformer:

  • Location: OneHotEncoded into orthogonal categorical vectors (with handle_unknown='ignore').
  • Numeric Features: Scaled and multiplied by fitted regression coefficients $\beta_i$.
  • Linear Combination: $\hat{y} = \beta_0 + \sum_{i=1}^n \beta_i X_i$.
  • Automatic Persistence: Automatically recorded in SQLite database with full timestamp.
